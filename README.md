# Hope Charity — Easy-to-use website

This is a polished charity website plus a simple editor at `/admin/`.

## Easiest use
Open `admin/index.html` in a browser. Change the text and choose photos from your phone. The editor can save the content on that device and download an updated `hope-charity-content.json`.

## For a truly live no-code workflow
For edits to automatically appear on a public website from any device, deploy the site with the Decap CMS version supplied previously (GitHub + Netlify + CMS login). The `/admin/` in this package is intentionally simple for local editing, but it does not by itself provide cloud synchronization.

## Starter content
The starter site uses information visible in the supplied Hope Charity TikTok screenshots. It does not invent a registration number, formal mission statement, physical address, or email.
